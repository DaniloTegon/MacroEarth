# Asset Credits

The 110-entry stratagem catalog, departments, display names, input sequences, and PNG icon set are based on release v1.0.10 (2026-09-23) of [Helldivers 2 Stratagem JSON Generator](https://github.com/k33bs/Helldivers-2-Stratagem-JSON-Generator). Four additional mission-only codes (Activate E-711 Extraction Drill, Aquifer Drill, Portable Comms Relay, and Reinforcement Pods) were added from the [Helldivers Wiki stratagem data](https://helldivers.wiki.gg/wiki/Stratagems). The generator repository is MIT licensed. The catalog's icon source is [Helldivers 2 Stratagems icons SVG](https://github.com/nvigneux/Helldivers-2-Stratagems-icons-svg), whose maintainer states that the icons may be reused with permission; retain this attribution when redistributing.

Sixteen legacy stratagem SVGs in `assets/stratagems` are from the [Helldivers Wiki](https://helldivers.wiki.gg/wiki/Stratagems). The wiki states that page content is licensed under CC BY-NC-SA 4.0 unless an asset says otherwise. Check the original asset pages and license before redistributing these legacy assets, especially commercially.

The `reinforce.svg` fallback was created for this project. This application is an unofficial fan utility and is not affiliated with Arrowhead Game Studios or Sony Interactive Entertainment.

`super_earth_emblem.svg` is a project-made vector adaptation of the emblem image supplied as a user reference. The official Super Earth icon is marked in copyright by its source and is not bundled here.
